☕ Café Website — AI-Assisted Web Development Project

A modern and responsive café website designed with a focus on clean UI, visual appeal, user experience, and mobile responsiveness.

This project was developed using AI-assisted web development, with hands-on customization and refinement of the design, styling, responsiveness, and functionality.

🌐 Live Demo

🔗 Live Website: https://smoky-coffee-cafe.vercel.app/

---

📌 About the Project

The goal of this project was to create a visually appealing online presence for a café that feels modern, warm, and premium while remaining easy to navigate across different devices.

The website includes a responsive layout, café-focused sections, customized styling, and interactive elements to provide a smooth browsing experience.

---

✨ Features

- 📱 Fully responsive design
- ☕ Modern café-themed interface
- 🎨 Customized colour palette and styling
- 🖥️ Responsive layouts for desktop, tablet, and mobile
- 📋 Menu section
- 📍 Contact & location section
- 📲 Mobile-friendly navigation
- ✨ Interactive UI elements
- ⚡ Fast and lightweight frontend
